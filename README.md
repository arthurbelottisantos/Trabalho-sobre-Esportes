# Trabalho-sobre-Esportes
Esse trabalho é sobre basquete, esse projeto foi criado com a intenção de falar sobre o basquete de forma básica.
Conteúdo
O site fala sobre:
quando o basquete foi criado e os benefícios de praticar esse esporte.
eu adicionei um botão de curtida e um botão de curiosidade.
Curiosidade:Você sabia? No primeiro jogo de basquete da história, em 1891, as cestas eram na verdade cestas de pêssego e não tinham fundo vazado. Toda vez que alguém pontuava, precisavam subir em uma escada para pegar a bola!
